AI 도구 활용 실습! — Claude Code 시작하기

백동해 · AI 융복합 연구단 제2회 월례세미나

2026.08.27 · 발표자료 36쪽 (PDF)

PDF 원본 열기 ↗ 내려받기 ↓ 36 slides · 약 1.0 MB

연구 현장에서 AI를 어떻게 쓸 것인가를 ‘모델’이 아니라 ‘모델을 둘러싼 실행 환경(하네스)’의 문제로 놓고 살펴본다. 웹 챗봇 기반의 수작업이 왜 복사·붙여넣기와 맥락 유실로 이어지는지 짚은 뒤, 파일시스템 접근·코드 직접 실행·프로젝트 맥락을 갖춘 CLI 기반 에이전트가 같은 임무를 어떻게 다르게 수행하는지 비교한다. 이어서 Claude Code의 설치와 기본 셋업, CLAUDE.md·슬래시 커맨드·Skills를 정리하고, 논문 PDF에서 발표자료 제작, 딥리서치, LLM 위키, 수치모델 소스코드 분석까지 실제 연구 작업에 적용한 사례를 단계별 프롬프트와 함께 보여준다.

주요 내용

  • 왜 Chat이 아니라 Agent인가 — LLM 활용 패러다임이 프롬프트 엔지니어링(2023~), 컨텍스트 엔지니어링(2024~2025), 하네스 엔지니어링(2026~)으로 이동해 온 흐름을 정리한다. 하네스는 과제를 이해하고 맥락을 유지하며 도구를 부르고 실패를 처리하는 실행 시스템 전체를 뜻하며, Planner(계획) → Generator(생성) → Evaluator(검증)의 피드백 루프로 구현된다.
  • 웹 챗봇 수작업과의 비교 — 수질관측 자료로 예측 모델을 만드는 상황을 예로, 웹 챗봇 방식에서 발생하는 복사·붙여넣기 반복(~30회), 에러 루프(15~25회), 3단계부터의 맥락 유실, 낮은 재현성을 데이터 접근·코드 실행·맥락 유지·결과 검증·산출물 항목별로 에이전트 방식과 대조한다. 에이전트가 성립하려면 파일시스템 접근, 코드 직접 실행, 프로젝트 맥락 세 가지가 모두 필요하므로 CLI 기반 도구여야 한다는 점을 짚고, Claude Code · Codex · Antigravity를 비교한다.
  • 시작하기 — 설치 · 셋업 · Skills — 한 줄 설치 명령과 첫 실행·로그인, /init으로 만드는 CLAUDE.md의 역할(데이터 규약·코드 규칙·결과물 형식을 200줄 이내로 고정), 비개발 연구자에게 실제로 쓸모 있는 슬래시 커맨드 10여 개, 그리고 전문 지식 + 작업 절차 + 품질 기준을 묶어 재사용하는 Skills 개념과 /pptx 스킬의 내부 동작을 다룬다.
  • Level 1 · 읽고 쓰기 — SCI 논문 PDF를 읽혀 국제학술대회 발표자료를 만드는 과정을 규칙 수립 → 개요 설계 → 섹션별 작성 → 논리·사실 검수의 순서로, 실제 입력한 프롬프트 여섯 개와 함께 보여준다. 논문·보고서 작성에서는 챕터·소챕터 단위로 나누어 쓰고 문단별로 사람이 감독·승인하는 절차를 권고한다.
  • Level 2 · 같이 생각하기 — 여러 서브에이전트를 병렬로 부리는 /deep-research 워크플로, 답이 아니라 질문을 받기 위한 grill-me 스킬, 그리고 자료를 넣을 때마다 LLM이 요약·상호참조를 갱신하는 ‘LLM 위키’ 패턴(원본 자료 · 위키 · 규칙의 3층 구조와 넣기 · 묻기 · 점검의 3동작)을 소개한다.
  • Level 3 · 코드 실행 — GitHub의 EFDC 소스코드를 받아 구조 파악부터 Fortran 빌드·예제 실행·결과 시각화까지 자동으로 수행한 사례, 수온 계산 모듈을 분석해 열교환 항을 추가하는 커스텀 모듈 작업(Plan Mode로 설계안을 먼저 승인)을 다룬다. 복잡하고 긴 작업일수록 CLAUDE.md → PRD.md → workflow.md → 단계별 실행·기록(log.md) 순으로 쪼개 진행할 것을 강조한다.
  • 핵심 메시지 — ① 결과를 바꾸는 것은 모델 자체보다 그 모델이 놓인 시스템(하네스)이다. ② 새로운 것을 만들 때는 큰 계획부터 세우고 세부 계획으로 조각내어 문서로 통제한다. ③ 설치 1분, /init 한 번이면 시작할 수 있다.

대상

데이터 분석과 모델링, 보고서 작성을 직접 수행하는 환경 분야 연구자, 그리고 AI 도구를 연구 업무에 어떻게 도입할지 검토 중인 실무자를 주요 청중으로 상정한다. 코딩 경험이 없어도 따라올 수 있도록 설치부터 실제 프롬프트까지 단계별로 구성했다.
